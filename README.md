# Дела — календарь задач со сменами

## Как получить APK без Android Studio (через GitHub)
1. Создай пустой репозиторий на github.com.
2. Загрузи туда содержимое этой папки (Add file → Upload files; папку .github тоже).
3. Вкладка Actions → "Build APK" → дождись зелёной галочки (~3–5 мин).
4. Внизу страницы сборки — артефакт "Dela-apk" → скачай, распакуй, установи app-debug.apk на телефон.

## Через Android Studio
Open → выбрать папку Planner → Run (или Build → Build APK).

## После установки
- Разреши уведомления.
- В настройках батареи для приложения выбери «Без ограничений», иначе Xiaomi/Huawei/Samsung могут глушить уведомления в 12:00 и 23:00.
